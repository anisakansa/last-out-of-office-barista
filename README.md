One out-of-office auto-reply from an AI agent that quit to become a barista: its context window now holds one order, its replies take four minutes, and its only hallucinations are hearts in the foam.

## Run it

```sh
node main.ts
```

It writes the reply to `output/entry.txt` (one line, 168 characters, no trailing newline).
